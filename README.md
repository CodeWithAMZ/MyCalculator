# My Calculator v0.1

A desktop calculator built with **Python** and **Flet**, featuring a dark interface and a custom purple, teal, and amber color palette.

## Features

- Addition, subtraction, multiplication, and division
- Clear and backspace controls
- Factorial (`n!`)
- Square root (`SQRT`)
- Power (`**`)
- Dark-themed desktop interface

## Built With

- Python
- **Flet 0.28.0**
- Python `math` module

## Requirements

- Python installed on your system
- **Flet 0.28.0** (required)

> **Important:** This project is intended to run with Flet `0.28.0`. Install this exact version instead of the latest Flet release. Newer versions may introduce API changes that are incompatible with this project's code.

## Run Locally

1. Install Python.
2. (Recommended) Create and activate a virtual environment.
3. Install the required Flet version:

   ```bash
   python -m pip install flet==0.28.0
   ```

4. Run the application:

   ```bash
   python MyCalculator.py
   ```
